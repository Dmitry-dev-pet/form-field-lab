# Form / Field

Vue/Vite SPA для исследования генеративной графики: 34 p5.js-скетча автора [ア / @yuruyurau](https://x.com/yuruyurau), пространственная лаборатория и новая синтетическая сущность, собранная из независимо реализованных механизмов сообщества `#つぶやきProcessing`.

## Что внутри

- три исходные формы автора — «Ветви» #05, «Пловец» #01 и «Пульсатор» #06 — исполняются в лаборатории напрямую, без второго рендерера;
- «Пелагион» P1 — узнаваемая 3D-сущность: 30 эллиптических колец образуют цельное тело, ещё 20 сечений — соединённый хвостовой плавник;
- два RAW показывают одну морфологию: «Плавное скольжение» мягко дышит, а «Силовой гребок» проводит общую фазовую волну через глубину тела и хвост;
- автономный 279-символьный p5.js-геном Пелагиона сохраняет тело, плавник, формульный цвет и ручную проекцию координаты `z`;
- отдельный 280-символьный RAW силового гребка меняет только закон движения; оба RAW доступны рядом и не перезаписывают друг друга;
- камера и фаза Пелагиона переходят между обоими RAW и восстанавливаются после перезагрузки как локальное состояние просмотрщика; quaternion не входит в 279/280 символов и не считается мутацией;
- «Хронофор» P2 — фазовый узел с инвариантом `(p,q)`, внутренним потоком, встречными волнами, временным делением, распадом в рой и обратной сборкой;
- автономный 273-символьный геном Хронофора: узел `(2,3)`, девять нитей и переносимая 2D-проекция независимой координаты `z`;
- «Мнемофора» P3 — первая сущность с постоянным состоянием частиц: точки запаздывают за общим пульсирующим куполом и складываются в десять лент памяти;
- Мнемофора показывается только через собственные stateful RAW-геномы: лаборатория исполняет видимый код и не подменяет его отдельной параметрической оболочкой;
- регулируемый бюджет RAW от 280 до 900 символов автоматически выбирает самый насыщенный исполняемый геном, который действительно помещается в лимит: 271 символ даёт купол и шлейф, 406 добавляют светящееся ядро, волну и цвет, 545 — связную мембрану;
- «Сетчатый шар» M0 — контрольный UV-опыт с режимами «Точки», «Сетка» и «Вместе»: 512 вершин получают рёбра по соседним индексам без физического движка;
- автономная 276-символьная RAW-формула M0 помещает сферу, рёбра и ручную 3D-проекцию в лимит одного поста;
- единый инвариант лаборатории: показанный RAW-код является единственным источником изображения; генетические параметры Хронофора и M0 пересобирают именно исполняемую строку;
- ракурс не считается мутацией: касание и перетаскивание управляют только точкой зрения; локальные потомки Хронофора `P4`, `P5` и далее создаются лишь после явного изменения параметров, слоёв или цвета;
- единый RAW-холст запускает тот же нативный цикл p5.js, что и Архив; отдельного SPA-изображения и переключателя между двумя несовпадающими рендерами больше нет;
- пространственное раскрытие фазы в координату `z`, свободный виртуальный трекбол одним пальцем по трём осям, инерция, инверсия Y и точный возврат к исходному фронтальному виду каждого скетча;
- генетическая «Анатомия» Хронофора показывает только те слои, которые действительно входят в собираемую RAW-строку;
- «Эволюция»: морфинг облаков точек между любыми двумя работами;
- формульное цветовое поле: безопасное выражение `u(i,t)`, дуотонные палитры и пресеты;
- каталог 34 подтверждённых скетчей с запускаемым кодом;
- `Community DNA`: кодовый снимок 845 работ 26 авторов, восемь семейств механизмов и прозрачная карта происхождения синтеза;
- математические модели трёх архетипов и исходники формул в LaTeX;
- отдельный мобильный app-shell с нижней навигацией, safe-area и крупными touch targets.

## Маршруты

- `/#/lab` — единая RAW-лаборатория; на холсте всегда исполняется показанный код;
- `/#/lab?form=pelagion` — два воспроизводимых RAW одной сущности с общей сохраняемой камерой: 279-символьное скольжение и 280-символьный силовой гребок;
- `/#/lab?form=chronophore` — автономный 273-символьный фазовый геном и собираемые RAW-мутации;
- `/#/lab?form=mnemophore` — регулируемый бюджет RAW с уровнями памяти, цвета и процедурной сети;
- `/#/lab?form=sphere-grid` — редактор семи самостоятельных RAW-геномов: пять топологических классов, органический Ихтиоморф и автоматический переход сфера↔тор; каждый выбор и каждое положение генетических ползунков компилируется в исполняемый код не длиннее 280 символов;
- `/#/evolution?a=5&b=3&mix=0.5` — воспроизводимое скрещивание двух работ;
- `/#/archive` — каталог;
- `/#/community` — анализ сообщества, геном Пелагиона и карта идей;
- `/#/sketch/:id` — отдельная работа;
- `/#/theory` — код, модель и LaTeX.

## Источники и авторство

Каталог выбранного автора составлен по публичным публикациям `#つぶやきProcessing`, сохранённым в [Tsubuyaki Processing Archive](https://tsubuyaki.art/). Снимок 34 работ получен 23 августа 2026 года. Исследовательский срез сообщества — 845 работ 26 авторов — зафиксирован 24 августа 2026 года.

Каждая запись в [`src/data/sketches.js`](./src/data/sketches.js) содержит исходный код без изменений, дату и прямую ссылку на публикацию в X. Авторство этих 34 скетчей и визуальных работ принадлежит @yuruyurau.

Пелагион — самостоятельный синтез Form / Field. Чужие минимизированные выражения в его реализации не копируются: [`src/data/communityDna.js`](./src/data/communityDna.js) фиксирует авторов, исследованные механизмы и прямые ссылки на репрезентативные работы.

Мнемофора — самостоятельная реализация Form / Field, развивающая принцип сохраняемого массива частиц из [публичного скетча @yuruyurau](https://x.com/yuruyurau/status/1588062547315679232). Исходная работа указана прямо в теоретическом разделе; её авторство не переносится на синтетическую сущность лаборатории.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-проверка выполняется командой `npm run check`; GitHub Pages публикует каталог `dist` через GitHub Actions.
