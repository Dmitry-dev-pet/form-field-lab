# Form / Field

Vue/Vite SPA для исследования генеративной графики на основе p5.js-скетча автора [ア / @yuruyurau](https://x.com/yuruyurau).

## Что внутри

- три параметрические формы автора — «Ветви» #05, «Пловец» #01 и «Пульсатор» #06 — с переключателем и собственными слайдерами;
- пространственное раскрытие фазы в координату `z`, вращение одним пальцем, инерция, инверсия Y и точный возврат к исходному фронтальному виду каждого скетча;
- динамическая «Анатомия»: независимое отключение характерных слоёв выбранной формулы;
- «Эволюция»: морфинг облаков точек между любыми двумя работами;
- формульное цветовое поле: безопасное выражение `u(i,t)`, дуотонные палитры и пресеты;
- каталог 34 подтверждённых скетчей с запускаемым кодом;
- математические модели трёх архетипов и исходники формул в LaTeX;
- отдельный мобильный app-shell с нижней навигацией, safe-area и крупными touch targets.

## Маршруты

- `/#/lab` — лаборатория параметров и анатомия формулы;
- `/#/evolution?a=5&b=3&mix=0.5` — воспроизводимое скрещивание двух работ;
- `/#/archive` — каталог;
- `/#/sketch/:id` — отдельная работа;
- `/#/theory` — код, модель и LaTeX.

## Источники и авторство

Каталог составлен по публичным публикациям `#つぶやきProcessing`, сохранённым в [Tsubuyaki Processing Archive](https://tsubuyaki.art/). Снимок каталога получен 23 августа 2026 года.

Каждая запись в [`src/data/sketches.js`](./src/data/sketches.js) содержит исходный код без изменений, дату и прямую ссылку на публикацию в X. Авторство исходных скетчей и визуальных работ принадлежит @yuruyurau; этот проект является исследовательским интерфейсом и явно сохраняет атрибуцию.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-проверка выполняется командой `npm run check`; GitHub Pages публикует каталог `dist` через GitHub Actions.
