# Form / Field

Интерактивная лаборатория генеративной графики на основе p5.js-скетча автора [ア / @yuruyurau](https://x.com/yuruyurau).

## Что внутри

- параметрическая версия исходной формулы со слайдерами;
- «Анатомия»: независимое отключение симметрии, пульсации, ряби и волокон;
- «Эволюция»: морфинг облаков точек между любыми двумя работами;
- каталог 34 подтверждённых скетчей с запускаемым кодом;
- математическая модель и исходники формул в LaTeX.

## Источники и авторство

Каталог составлен по публичным публикациям `#つぶやきProcessing`, сохранённым в [Tsubuyaki Processing Archive](https://tsubuyaki.art/). Снимок каталога получен 23 августа 2026 года.

Каждая запись в [`sketches.js`](./sketches.js) содержит исходный код без изменений, дату и прямую ссылку на публикацию в X. Авторство исходных скетчей и визуальных работ принадлежит @yuruyurau; этот проект является исследовательским интерфейсом и явно сохраняет атрибуцию.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173`.
