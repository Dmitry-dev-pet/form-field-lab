    Under the surface

    Код и математика

    Каждый кадр — это параметрическое отображение индекса точки в координаты холста. Формулы ниже используют те же параметры, что и слайдеры сверху.

    01 / MODEL

    Математическая модель

    Для точки с индексом \(i\), где \(0 \le i < N\), вводим четыре промежуточные величины:

    \[ \begin{aligned} y_i &= \frac{i}{995}, \\ k_i &= \left(4+\cos(\omega y_i+t)\right)\cos\left(\frac{i}{q}\right), \\ e_i &= \frac{y_i}{5}-11, \\ d_i &= \sqrt{k_i^2+e_i^2}-\delta, \\ c_i &= \frac{d_i}{2}-\frac{t}{2}+(i\bmod m)\frac{3\varphi}{m}. \end{aligned} \]

    После этого точка попадает на экран в координаты:

    \[ x_i=(R+k_i^2)\cos(c_i)+200, \] \[ \begin{aligned} Y_i={}&H\sin\left(\frac{c_i}{3}\right)+200 \\ &+d_i^2\frac{P}{3}\sin(3t-d_i)+3\sin(2k_i) \\ &+\frac{y_i k_i}{F}\left(e_i+\sin(4e_i-4d_i)\right). \end{aligned} \]
    • N — количество точек
    • m — количество форм
    • R, H — размер и высота
    • ω — частота волн
    • P — сила пульсации
    • φ — фазовый шаг
    • q — плотность рёбер
    • δ, F — смещение и длина волокон

    Пресет Original: \(N=20000,\ m=3,\ R=79,\ H=99,\omega=31,\ P=3,\ \varphi=8,\ q=99,\delta=6,\ F=13\).

    02 / SOURCE

    Итоговый код ядра

    const ORIGINAL = {
  speed: 1, forms: 3, radius: 79, height: 99,
  waveFrequency: 31, pulse: 3, pointCount: 20000,
  alpha: 96, phaseStep: 8, radialDivisor: 99,
  distanceOffset: 6, featherDivisor: 13
};

function render() {
  ctx.fillStyle = settings.backgroundColor;
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  const point = hexToRgb(settings.pointColor);
  ctx.fillStyle = `rgba(${point.r}, ${point.g}, ${point.b}, ${settings.alpha / 255})`;

  const formCount = Math.max(1, Math.round(settings.forms));
  const normalizedPhaseStep = settings.phaseStep * 3 / formCount;

  for (let i = settings.pointCount; i--;) {
    const y = i / 995;
    const k = (4 + cos(y * settings.waveFrequency + time))
      * cos(i / settings.radialDivisor);
    const e = y / 5 - 11;
    const d = mag(k, e) - settings.distanceOffset;
    const c = d / 2 - time / 2
      + (i % formCount) * normalizedPhaseStep;

    const x = (settings.radius + k * k) * cos(c) + 200;
    const pulse = d * d * (settings.pulse / 3)
      * sin(time * 3 - d);
    const ripple = 3 * sin(k * 2);
    const feather = y / settings.featherDivisor * k
      * (e + sin(e * 4 - d * 4));
    const screenY = settings.height * sin(c / 3)
      + 200 + pulse + ripple + feather;

    ctx.fillRect(x, screenY, 1, 1);
  }
}
