# Deterministic Form / Field fonts

These font files are stored locally so video layout and glyph metrics do not depend on the host operating system.

Source repository: `google/fonts`, commit `6a003b5eb672dc8bf5bff5937cf5863f8b175445`.

- `BarlowCondensed-Regular.ttf` and `BarlowCondensed-SemiBold.ttf` — SIL Open Font License 1.1; see `licenses/BarlowCondensed-OFL.txt`.
- `CormorantGaramond-Italic-wght.ttf` — SIL Open Font License 1.1; see `licenses/CormorantGaramond-OFL.txt`.
- `IBMPlexMono-Regular.ttf` — SIL Open Font License 1.1; see `licenses/IBMPlexMono-OFL.txt`.

The binaries are inputs to the deterministic render recipe and are listed by SHA-256 in each video's `provenance.json`.
