# Видео Form / Field

`entity-001.html` — вертикальная постановка пилотного выпуска на основе скетча №36. Она использует один массив частиц: сначала выполняет исходную механику автора, затем внешняя видеопостановка плавно включает автономную RAW-мутацию.

Параметры камеры, титров и перехода не входят в RAW-геном.

Для локального рендера нужны Python Playwright, Chrome и FFmpeg:

```bash
python3 scripts/video/render_entity_001.py
```

Команда создаёт `public/videos/entity-001/entity-001.mp4` и `cover.png`. Исходный WebM временный; флаг `--keep-webm` сохраняет его рядом с MP4.
